Справочник описывает язык Java и платформу на базе Java SE 25: от лексики и системы типов до модели памяти, стандартного API и продвинутых тем. Материал изложен строго и формально, но с постоянным упором на практику — так, как это нужно человеку, который пишет и сопровождает реальный код, а не готовится к академическому экзамену по теории языков.

## Audience

Основная аудитория — практикующие разработчики: те, кто уже пишет на Java и кому нужен точный, полный и удобный для навигации источник ответов на «языковые» вопросы. Предполагается знакомство с программированием; справочник не учит программировать с нуля, но и не требует знания спецификации — он сам объясняет её строго и по-человечески.

## What This Reference Is Not

Это не пошаговый учебник для начинающих и не дословный пересказ JLS. Спецификация — один из источников, а не форма подачи: сухие формулировки JLS здесь дополняются развёрнутыми определениями, объяснениями «почему так», примерами и разбором ошибок. Это и не замена официальной документации API и инструментов JDK — на них справочник опирается и ссылается, но фокус держит на языке и платформе.

## What You Get From the Book

После работы с любой главой читатель должен не просто «узнать про X», а получить практический результат: уметь отличать близкие понятия, предвидеть характерные ошибки и знать, где в первоисточнике искать точную формулировку. Каждая глава строится вокруг такого поведенческого результата.

## Structure at a Glance

Справочник разбит на части по слоям знания. Part I — язык Java (нормативная база плюс развёрнутые определения и практика). Part II — виртуальная машина (JVMS): формат class-файла, байткод, верификация. Part III — практика JDK: компиляция, запуск, модули, инструменты. Part IV — язык и стандартные библиотеки под углом сертификации (здесь уместны экзаменационные ловушки). Part V — стандартный API на практике. Part VI — продвинутые темы. Part VII — опциональная инженерная практика, по отдельному решению.

Нумерация глав сознательно пересобрана относительно JLS ради удобства разработчика (например, Enums, Records и Annotations вынесены в отдельные главы). Полное оглавление со всеми главами и подразделами — в [[Java Complete Full Reference]]; здесь оно намеренно не дублируется.
