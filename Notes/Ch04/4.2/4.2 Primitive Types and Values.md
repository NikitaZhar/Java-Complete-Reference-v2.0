# 4.2 Primitive Types and Values

Восемь примитивных типов — тот уровень, на котором Java соприкасается с железом: значения хранятся непосредственно, операции ложатся на инструкции процессора, `null` и объектных накладных расходов нет. Секция разбирает каждый тип не как строку в таблице, а с его практикой и характерными ошибками: где тип уместен, где переполняется, где молча теряет точность. Чем примитив отличается от ссылочного типа в принципе — уже в [[4.1.3 High-Level Classification of Types]]; правила преобразований между типами — Ch. 5; семантика операторов — Ch. 15.
