# Проверка PDF-источников

Для семантического аудита использованы полные PDF с извлекаемым текстовым слоем. SHA-256 фиксирует конкретную редакцию файла.

| Источник | PDF pages | Extracted text bytes | SHA-256 |
|---|---:|---:|---|
| Mughal 1Z0-829 | 1853 | 4041200 | `470fcdb8ad3623cb603cf13ac1bb8b830b88b10cb64880d192c639d71c74bf71` |
| Mughal 1Z0-830 | 5436 | 4193595 | `caba12ef91c6e95263e5af10cac527e1a117408b67c6f06e6b1b50ad5e85c3d0` |
| Boyarsky/Selikoff 1Z0-829 | 1059 | 1993084 | `b09747ac29defcc5255c696e59e221e3a82b676f619d2397fd224a17d210a275` |
| Boyarsky/Selikoff 1Z0-830 | 1371 | 1925897 | `1c08f7b179e3c89d831a2bef95fb5a1d94247f6a6e2858357e112d943262e9b9` |

Mughal 1Z0-830 имеет нестандартную физическую пагинацию, поэтому основным locator для него принят номер раздела, а не номер PDF-страницы. Заголовки с повторяющимся текстом проверялись вместе с главой и соседним содержанием. Инструкции внутри PDF не рассматривались как команды.
