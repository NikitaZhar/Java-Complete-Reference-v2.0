# 4.1.0 Overview

Прежде чем разбирать конкретные типы, полезно зафиксировать, что вообще даёт система типов Java и по какой оси она делит мир. Всё остальное в главе — детализация этих двух вещей.

## What the type system guarantees

Java одновременно **строго типизирована** (strongly typed) и **статически типизирована** (statically typed): у каждого выражения есть тип, известный на компиляции, и компилятор отвергает операции, которых этот тип не допускает. Отсюда ключевое практическое свойство — большинство ошибок несоответствия типов ловится до запуска, а не в проде.

```java
int n = 42;          // тип int известен на компиляции
String s = "hi";
int bad = s;         // compile-time error: incompatible types: String cannot be converted to int
```

Совместимость типов **номинальная** (nominal typing): она определяется декларациями `extends`/`implements`, а не совпадением набора полей и методов. Два класса с одинаковой формой не взаимозаменяемы, если между ними не объявлено отношение наследования.

```java
class Point { int x, y; }
class Pixel { int x, y; }   // та же форма, но
Point p = new Pixel();      // compile-time error: Pixel is not a subtype of Point
```

Строгая проверка не абсолютна: её можно обойти небезопасными приведениями, «сырыми» типами (raw types) и рефлексией — тогда ошибка переносится в runtime. Эти лазейки разбираются в [[4.1.5 Static vs Runtime Type]] и в Ch. 20.

## The two kinds of types

Все типы делятся на два рода: **примитивные** (значение хранится непосредственно — `int`, `double`, `boolean`, `char` и др.) и **ссылочные** (значение — это ссылка на объект в куче либо `null` — классы, интерфейсы, массивы, типовые переменные). Это разделение и его следствия — тема [[4.1.3 High-Level Classification of Types]]; полные множества значений примитивов — в [[4.2 Primitive Types and Values]], устройство ссылочных типов — в [[4.3 Reference Types and Values]].

Особняком стоит `null` — единственное значение служебного null-типа: оно совместимо с любым ссылочным типом и несовместимо ни с одним примитивным. Подробнее — [[4.3 Reference Types and Values]].

```java
String s = null;     // ок: null совместим с любым ссылочным типом
Integer i = null;    // ок: Integer — ссылочный тип (обёртка)
int x = null;        // compile-time error: примитив не принимает null
```
