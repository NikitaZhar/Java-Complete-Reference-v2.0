Логических литерала ровно два — `true` и `false`; это единственные значения типа `boolean`.

```java
boolean ready = true;
boolean done  = false;
```

Java различает регистр, а сами литералы пишутся строчными буквами. `True` или `FALSE` — это не логические литералы, а идентификаторы, поэтому компилятор их не найдёт.

```java
boolean a = True;    // ошибка компиляции: cannot find symbol (True — не литерал)
boolean b = true;    // правильно
```

В отличие от C и C++, число не является логическим значением. В условии (`if`, `while`, `for`, `do-while`) и в логических операторах допустимо только выражение типа `boolean`.

```java
if (1) { }           // ошибка компиляции: int нельзя использовать как boolean
int n = 5;
if (n) { }           // ошибка компиляции по той же причине
if (n != 0) { }      // правильно: явное сравнение даёт boolean
```

## Common Mistakes

1. **Число вместо условия (привычка из C).** `if (count)` → ошибка. Правильно: `if (count != 0)`.
2. **Литерал с заглавной буквы.** `boolean ok = True;` → «cannot find symbol». Правильно: `true` строчными.
3. **Присваивание вместо сравнения.** `if (flag = true)` компилируется (это присваивание, дающее `true`), но почти всегда это ошибка логики. Правильно: `if (flag)` или `if (flag == true)`.
