Литерал — это фиксированное значение, записанное прямо в исходном коде: число, символ, строка, логическое значение или `null`. Лексически литерал — это один токен, обозначающий константное значение; во время выполнения он не вычисляется. Этот раздел описывает **лексические формы** литералов — как они записываются и какого типа значение порождают. Семантика самих типов (диапазоны, IEEE 754, UTF-16) — это глава 4; преобразования и продвижения — глава 5; операторы над значениями — глава 15; внутреннее представление в constant pool — Part II (JVMS). Здесь — только запись.

## Kinds of Literals

Грамматика выделяет шесть видов литералов:

```
Literal:
    IntegerLiteral
    FloatingPointLiteral
    BooleanLiteral
    CharacterLiteral
    StringLiteral
    NullLiteral
```

| Категория | Тип | Примеры |
|---|---|---|
| Целочисленные | `int`, `long` | `42`, `0xFF`, `0b1010`, `123L` |
| С плавающей точкой | `float`, `double` | `3.14`, `6.022e23`, `0x1.0p4f` |
| Логические | `boolean` | `true`, `false` |
| Символьные | `char` | `'A'`, `'\n'`, `'Ω'` |
| Строковые | `String` | `"Hello"`, текстовый блок `"""…"""` |
| Null-литерал | null type | `null` |

Литералы примитивных типов и `String` — простейшие константные выражения времени компиляции; подробнее о том, где это важно, — [[3.10.7 Constant Expressions]].
