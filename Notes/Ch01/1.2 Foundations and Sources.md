Справочник опирается на пять источников, которые используются вместе: JLS, JVMS, документацию Oracle, книги Boyarsky и книги Mughal.

## Source Groups

Нормативную основу дают две спецификации Oracle для Java SE 25: *The Java Language Specification* (JLS) — правила самого языка, и *The Java Virtual Machine Specification* (JVMS) — формат class-файла, байткод и исполнение. Практический и учебный слой дают документация Oracle (Java SE API и руководства по инструментам JDK) и две пары экзаменационных руководств: Boyarsky, *OCP Java SE 17/21 Developer* (1Z0-829, 1Z0-830), и Mughal, *OCP Java SE 17/21 Developer* (1Z0-829, 1Z0-830).

## How the Sources Combine

Источники сочетаются по типу вклада и не закреплены жёстко за частями книги. JLS задаёт правила и семантику языка, JVMS — устройство виртуальной машины и формат class-файла, документация Java SE API — контракты стандартных библиотек. Руководства JDK описывают инструменты и их использование. Книги Boyarsky и Mughal дают развёрнутые определения, объяснения «почему так», примеры и разбор типичных ошибок и ловушек. Они используются наравне с другими источниками при раскрытии темы в пределах её владельца; пропорция зависит от фактического покрытия материала.

Базовая версия справочника — Java SE 25. Материал книг по Java SE 17 и 21 сверяется с этой версией. При расхождении языковое правило проверяется по JLS SE 25, правило виртуальной машины — по JVMS SE 25, контракт стандартного API — по документации Java SE 25 API. Поведение, зависящее от конкретной реализации или версии JDK, отмечается отдельно.

## External Standards and the Java Memory Model

Помимо основных источников, язык и платформа используют внешние стандарты. Unicode определяет кодовые точки и свойства символов, используемые в правилах лексики и идентификаторов. IEEE 754 задаёт основу форматов и арифметики `float` и `double`, включая специальные значения и правила округления; конкретные правила Java определены в JLS. Эти темы раскрываются соответственно в главах 3 и 4 справочника.

Нормативные правила модели памяти Java (Java Memory Model, JMM) изложены в JLS SE 25, §17; их объяснение в справочнике — в Part I, Chapter 19.

- [JLS SE 25](https://docs.oracle.com/javase/specs/jls/se25/html/index.html) — правила и семантика языка.
- [JVMS SE 25](https://docs.oracle.com/javase/specs/jvms/se25/html/index.html) — устройство виртуальной машины и формат class-файла.
- [Java SE 25 API](https://docs.oracle.com/en/java/javase/25/docs/api/index.html) — контракты стандартных библиотек.
- [JDK 25 Documentation](https://docs.oracle.com/en/java/javase/25/) — руководства и инструменты JDK.
- [[Boyarsky 1Z0-829]] и [[Boyarsky 1Z0-830]] — руководства Jeanne Boyarsky и Scott Selikoff для экзаменов Java SE 17 и 21 соответственно.
- [[Mughal 1Z0-829]] и [[Mughal 1Z0-830]] — руководства Khalid A. Mughal и Vasily A. Strelnikov. Издание 1Z0-829 посвящено Java SE 17; локальный файл 1Z0-830 содержит части по Java SE 21 и Java SE 17.
