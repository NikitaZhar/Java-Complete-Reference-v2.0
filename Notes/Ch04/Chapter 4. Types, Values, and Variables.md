# Chapter 4. Types, Values, and Variables

Эта глава задаёт понятийный каркас, на который опирается весь остальной язык: что такое **тип**, что такое **значение** и что такое **переменная**, и как эти три вещи связаны. Для практика это не абстракция — именно отсюда растут правила присваивания, автоупаковка, разница между `==` и `equals`, значения по умолчанию у полей и обязательная инициализация локальных переменных. Коротко: тип — это статическое обещание компилятора о множестве допустимых значений и операций над ними; значение — конкретная сущность времени выполнения; переменная — именованная ячейка, хранящая значение объявленного типа. Глава **не** описывает преобразования между типами (это Ch. 5, Conversions and Contexts) и не разбирает generics по существу — их дом Ch. 20; здесь обобщённые формы появляются лишь как один из родов типа в общей классификации.
