Ошибки этого уровня — не про смысл программы, а про чтение грамматики и разбор токенов. Ниже — характерные случаи в формате «проблема → код → как правильно».

## Reading Optionality as a Default

Проблема: необязательный элемент `[x]` (или индекс *opt*) читают как «если опущен, подставляется значение по умолчанию».

```
MethodHeader:
    {MethodModifier} Result MethodDeclarator [Throws]
```

Как правильно: `[Throws]` значит лишь «раздела `throws` может не быть»; никакой «пустой throws» при этом не подразумевается. Семантика отсутствия части задаётся отдельно, а не грамматикой.

## Confusing Grammar Metasymbols with Java Syntax

Проблема: метасимволы нотации `[ ]` и `|` принимают за конструкции языка.

```
Statement:
    Block | IfThenStatement | WhileStatement
```

Как правильно: здесь `|` — это «одна из альтернатив» грамматики, а не побитовое ИЛИ; `[ ]` в правилах — «необязательно», а не индексация массива.

## Expecting else to Bind to the Outer if

Проблема: считают, что `else` относится к внешнему `if` по отступам.

```java
if (a)
    if (b) doB();
else doElse();   // на деле else относится к внутреннему if (b)
```

Как правильно: по грамматике `else` связывается с ближайшим незакрытым `if`; ставьте фигурные скобки, чтобы задать привязку явно.

## Mismatched > in Nested Generics

Проблема: число закрывающих углов не совпадает с числом открывающих в вложенных параметрах типа.

```java
List<List<Integer>>> x = null; // синтаксическая ошибка: три > при двух <
```

Как правильно: считать углы — число закрывающих `>` должно совпадать с числом открывающих `<`: здесь корректно `List<List<Integer>>`. В типовом контексте компилятор не склеивает соседние `>` в оператор сдвига (исключение из longest-match, [[3.5 Input Elements and Tokens]]), поэтому лишний `>` не «поглощается», а даёт именно синтаксическую ошибку.

## Maximal Munch Surprise

Проблема: соседние операторные символы неожиданно слипаются в один токен по правилу longest-match.

```java
int r = a--b;   // читается как (a--) b и не компилируется как разность
```

Как правильно: разделяйте символы пробелом, когда нужен другой разбор — `a - -b`.
