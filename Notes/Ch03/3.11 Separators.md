Разделитель (separator) — это токен-пунктуатор, который структурирует код: группирует, ограничивает и разделяет синтаксические конструкции. В отличие от операторов ([[3.12 Operators]]), разделители не вычисляют значение — они задают форму программы (границы блоков, списки аргументов, конец инструкции). Этот раздел — только каталог разделителей как токенов; их синтаксическая роль раскрывается в соответствующих главах (блоки и инструкции — Ch. 14, вызовы и создание объектов — Ch. 15, аннотации — Ch. 9, ссылки на методы — Ch. 15).

## The Separators

Java определяет двенадцать разделителей:

```
(   )   {   }   [   ]   ;   ,   .   ...   @   ::
```

| Разделитель | Назначение (кратко) | Где раскрывается |
|---|---|---|
| `( )` | группировка выражений, список параметров/аргументов, приведение типа | Ch. 14–15 |
| `{ }` | блоки, тела классов/методов, инициализаторы массивов | Ch. 8, 13, 14 |
| `[ ]` | объявление и доступ к массиву | [[Chapter 13. Arrays]] |
| `;` | завершение инструкции; разделитель в классическом `for` | Ch. 14 |
| `,` | разделение элементов в списках (параметры, аргументы, объявления) | Ch. 8, 14 |
| `.` | доступ к члену, квалификация имени | Ch. 6, 15 |
| `...` | varargs — параметр переменной арности | Ch. 8.4 |
| `@` | начало аннотации | Ch. 9.7 |
| `::` | ссылка на метод/конструктор (method reference) | Ch. 15.6 |

```java
int[] a = {1, 2, 3};                 // [] — массив, {} — инициализатор, , — разделитель
void log(String... args) { }         // ... — varargs
Runnable r = System::currentTimeMillis; // :: — ссылка на метод
@Override public String toString() { return "x"; } // @ — аннотация, () {} — разделители
```

Обратите внимание: `...` (три точки подряд) — отдельный токен-разделитель, а не три токена `.`; это результат правила longest match ([[3.2 Lexical Translations]]). Точно так же `::` — один токен, а не два двоеточия. Семантика всех этих конструкций — в указанных главах; здесь фиксируется лишь то, что перечисленные символы являются разделителями.
