Символьный литерал заключён в одинарные кавычки и содержит ровно один символ или одну escape-последовательность; его тип — `char`.

```java
char c       = 'A';        // обычный символ
char omega   = 'Ω';        // любой символ Unicode прямо из исходника
char newline = '\n';       // escape-последовательность
```

## Escape Sequences

| Последовательность | Значение |
|---|---|
| `\n` `\t` `\b` `\r` `\f` | перевод строки, табуляция, забой, возврат каретки, перевод страницы |
| `\\` `\'` `\"` | обратная косая, одинарная и двойная кавычки |
| `\ddd` | октальный код (`\000`–`\377`) |
| `\uXXXX` | символ Unicode по шестнадцатеричному коду |

```java
char tab   = '\t';
char quote = '\'';   // одинарную кавычку внутри '' обязательно экранировать
char back  = '\\';   // и обратную косую тоже
char oct   = '\101'; // 'A' через октальный код
```

Недопустимая escape-последовательность — ошибка компиляции. Разрешены только перечисленные выше.

```java
char bad = '\x41';   // ошибка компиляции: \x не является допустимым escape
```

## The \uXXXX Escape Is Special

`\uXXXX` обрабатывается не так, как `\n` и остальные escape. Обычные escape раскрываются на лексической стадии, внутри литерала, а `\uXXXX` — раньше, ещё до токенизации. Поэтому Unicode-escape кавычки или перевода строки способен «схлопнуть» литерал до того, как компилятор начнёт его разбирать, и вызвать неожиданную ошибку. Механизм и разбор таких ловушек — в разделе 3.3 Unicode Escapes; в символьных литералах достаточно помнить: для кавычки и перевода строки используйте обычные escape `'\''` и `'\n'`, а не Unicode-коды.

## Errors

```java
char empty = '';     // ошибка: символьный литерал не может быть пустым
char two   = 'AB';   // ошибка: допустим только один символ
// char nl = '<перевод строки>';  — «сырой» перевод строки внутри '' запрещён, нужен '\n'
```

## Common Mistakes

1. **Пустой или многосимвольный литерал.** `char c = '';` или `'AB'` → ошибка. Для нескольких символов нужен `String`: `"AB"`.
2. **Неэкранированные `'` и `\`.** `char q = ''';` → ошибка. Правильно: `'\''` и `'\\'`.
3. **«Сишные» escape.** `'\x41'`, `'\d'` недопустимы. Правильно: `'A'` или октальный `'\101'`.
4. **Unicode-escape для кавычки или перевода строки.** Раскрывается до токенизации и ломает литерал. Правильно: обычные `'\''` и `'\n'` (см. 3.3).
