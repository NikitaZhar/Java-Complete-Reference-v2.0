Комментарий — это входной элемент, который лексер распознаёт и отбрасывает вместе с пробелами ([[3.5 Input Elements and Tokens]]); на семантику программы он не влияет. Java знает две формы: традиционный комментарий `/* … */` и комментарий до конца строки `// …`. Разновидность традиционного, начинающаяся с `/**`, — это документирующий комментарий (Javadoc); лексически он обычный комментарий, а его структура и стиль — тема Part VI (см. Part VI, Ch. 63.6). Важно понимать, что комментарии не вкладываются и не имеют силы внутри литералов — именно здесь возникают типичные сюрпризы.

## The Two Forms

```
TraditionalComment:  /* text */     — всё от /* до ближайшего */ игнорируется
EndOfLineComment:    // text        — всё от // до конца строки игнорируется
```

Традиционный комментарий кончается на первом же `*/`, комментарий `//` — на ближайшем терминаторе строки ([[3.4 Line Terminators]]).

```java
int a = 1; /* это
             многострочный традиционный комментарий */ int b = 2;
int c = 3;  // до конца строки; здесь /* и */ ничего не значат
```

## Comments Do Not Nest

Три правила, вытекающие из грамматики: комментарии не вкладываются друг в друга; `/*` и `*/` не имеют особого значения внутри `//`-комментария; `//` не имеет особого значения внутри `/* … */`. Поэтому весь следующий фрагмент — один комментарий, заканчивающийся на первом `*/`:

```java
/* внешний /* // /** заканчивается здесь: */
int x = 5;   // код снова начинается тут
```

Попытка «вложить» комментарии ломает код, потому что первый `*/` закрывает всё:

```java
/* внешний /* внутренний */ этот текст уже КОД, а не комментарий */
// последняя */ вызовет ошибку компиляции: незакрытый комментарий/лишние токены
```

## Comments Inside Literals

Лексическая грамматика устроена так, что комментарии не распознаются внутри символьных, строковых литералов и текстовых блоков: последовательности `//`, `/*`, `*/` там — обычные символы данных, а не начало комментария.

```java
String url = "https://example.com";  // // внутри строки — часть значения, не комментарий
String s   = "/* not a comment */";  // эти символы входят в строку целиком
System.out.println(url);             // https://example.com
```
