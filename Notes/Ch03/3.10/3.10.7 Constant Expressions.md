Литералы напрямую связаны с понятием константного выражения времени компиляции: литерал примитивного типа или `String` — простейший его случай. Константное выражение вычисляется компилятором, а не во время выполнения, и складывается из литералов, `final`-констант примитивных и строковых типов и операций над ними.

```java
final int    SIZE = 2 * 3 * 7;      // 42, вычислено при компиляции
final String VER  = "Java " + 21;   // "Java 21", склеено при компиляции
```

Не всё, что выглядит константой, ею является: если хотя бы один операнд вычисляется во время выполнения или переменная не `final`, выражение перестаёт быть константным.

```java
final double R = Math.random();     // НЕ константа: значение известно только в рантайме
int a = 2, b = 3;
int sum = a + b;                    // НЕ константа: a и b не final
```

## Why It Matters at the Literal Level

Только константные выражения допустимы в трёх местах, и это самая частая практическая причина, по которой их вообще замечают: метки `case` в `switch`, значения аннотаций и инициализаторы `final`-полей. Переменная или вызов метода там недопустимы.

```java
final int OK = 200;
int code = 200;

switch (status) {
    case OK -> …      // ок: OK — константа
    case code -> …    // ошибка компиляции: code не является константой
}
```

```java
@interface Info { String value(); }

@Info("build-42")            // ок: строковый литерал — константа
@Info(buildName())           // ошибка компиляции: вызов метода — не константа
class Example { }
```

Равные строковые константы к тому же попадают в общий пул строк, поэтому две одинаковые константные строки ссылаются на один объект.

## Common Mistakes

1. **Непостоянная метка `case`.** `case threshold:` при не-`final`/вычисляемом `threshold` → ошибка. Правильно: объявить `static final` константу или использовать литерал.
2. **Метод или `Math.random()` как значение аннотации/константы.** `@Size(getMax())` → ошибка. Значение должно быть известно компилятору.
3. **`final`, но не константа.** `final int x = obj.field;` — `final`, но инициализирован не константой, поэтому в `case`/аннотации не подходит.
