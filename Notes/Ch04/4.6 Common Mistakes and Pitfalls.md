# 4.6 Common Mistakes and Pitfalls

Сводный блок ошибок уровня главы. Почти все они растут из одного корня — смешения уровней: тип против значения, статический тип против исполняемого, примитив против ссылки, ссылка против объекта. Ниже — самые частые, каждая с указателем на подраздел-дом; детальные наборы ловушек по темам — в [[4.1.8 Common Pitfalls]] (типы и значения) и [[4.2.15 Choosing a Primitive Type — Practical Guidelines and Pitfalls]] (примитивы).

## The mental-model traps

Поведение задаёт **исполняемый** тип, а не объявленный: переопределённый метод вызывается по фактическому типу объекта, что бы ни стояло в объявлении переменной ([[4.1.5 Static vs Runtime Type]]).

`==` у ссылок — это **тождество**, а не равенство содержимого: строки и обёртки сравнивают через `equals`; `==` — примитивам, `null` и проверке «тот же объект» ([[4.3 Reference Types and Values]], Ch. 49).

`null` — значение, означающее отсутствие объекта: разыменование даёт `NullPointerException`, а неявная распаковка `null`-обёртки роняет даже там, где ошибки не ждёшь ([[4.1.2 Definition of Value]], [[4.2.13 Boxing and Unboxing]]).

Целочисленное переполнение **молчит**, а `byte + byte` даёт `int`: результат может не влезть в исходный тип, и об этом не будет ни исключения, ни предупреждения ([[4.2.1 Integral Types]]).

Вещественные **приближённы**: `0.1 + 0.2 != 0.3`, `NaN` не равен себе, деньги — не в `double` ([[4.2.7 Floating-Point Types]]).

Приведение, которое **компилируется**, может упасть в runtime: downcast и `(Integer) someNumber` проверяются лишь при выполнении ([[4.1.5 Static vs Runtime Type]]).

Generics **инвариантны и стёрты**: `List<String>` не подтип `List<Object>`, а тип элемента в runtime недоступен ([[4.1.6 Subtypes and Supertypes]]; подробнее Ch. 20).

Аргументы передаются **по значению**: переприсваивание параметра не меняет переменную вызывающего; меняется лишь состояние общего объекта ([[4.1.7 Runtime Representation of Values]]).

Локальная переменная **не имеет** значения по умолчанию (в отличие от поля): чтение до инициализации — ошибка компиляции ([[4.2.14 Default Values and Initialization]]).

`final` фиксирует **ссылку**, а не объект: `final`-коллекцию всё ещё можно изменять ([[4.5 Variables]]).
