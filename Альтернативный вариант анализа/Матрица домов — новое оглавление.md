# Матрица домов — новое полное оглавление

## Нормативные правила

- Каждая строка ниже — минимальная тема текущего структурного уровня и имеет один теоретический дом. При написании главы строка может быть декомпозирована глубже, но её дом не меняется без записи решения.
- `Применение` объясняет только локальный контекст; определение и механизм заменяются односторонней ссылкой на дом.
- `source-required` означает обязательную закладку без разрешения заполнять её по памяти. До написания утверждаются официальный источник, версия и минимум один независимый практический источник.
- Exercises, certification, framework adapters и production recipes не вводят заново язык, JMM, архитектурные принципы или testing theory.
