Оператор (operator) — это токен, обозначающий операцию над одним, двумя или тремя операндами: арифметику, сравнение, логику, побитовые действия, присваивание. На лексическом уровне важен только каталог форм: какие последовательности символов являются операторными токенами и как они собираются по правилу longest match. Семантика — приоритеты, ассоциативность, продвижение типов, вычисление, перегрузка `+` для строк, поведение `>>>` — целиком относится к главе выражений и здесь не дублируется: подробнее см. Part I, Ch. 15 (Expressions and Operators).

## The Operators

Java определяет 38 операторных токенов:

```
=    >    <    !    ~    ?    :    ->
==   >=   <=   !=   &&   ||   ++   --
+    -    *    /    &    |    ^    %    <<    >>    >>>
+=   -=   *=   /=   &=   |=   ^=   %=    <<=   >>=   >>>=
```

Сгруппированы по роли: присваивание (`=` и составные `+=`, `-=`, …, `>>>=`); арифметика (`+ - * / %`); инкремент/декремент (`++ --`); сравнение (`== != < > <= >=`); логика (`&& || !`); побитовые и сдвиги (`& | ^ ~ << >> >>>`); условный тернарный (`? :`); стрелка лямбды (`->`).

```java
int a = 5, b = 2;
int sum  = a + b;      // + — бинарный арифметический
a += b;                // += — составное присваивание, эквивалент a = a + b
boolean t = a > b && b > 0;   // >, && — сравнение и логическое И
int m = (a > b) ? a : b;      // ?: — тернарный оператор
Runnable r = () -> {};        // -> — стрелка лямбды
```

## Longest-Match Assembly

Операторные символы собираются жадно ([[3.2 Lexical Translations]]): соседние символы без пробела склеиваются в самый длинный допустимый оператор. Отсюда две практические тонкости.

Во-первых, `>>>=` — это один токен (беззнаковый сдвиг с присваиванием), а не комбинация; чтобы получить другой разбор, нужен пробел.

```java
int x = 8;
x >>>= 1;        // один оператор >>>= : беззнаковый сдвиг вправо на 1 с присваиванием
```

Во-вторых, есть исключение из longest match: в контексте типа соседние `>` не склеиваются в `>>`/`>>>`, чтобы работали вложенные дженерики `List<List<String>>` ([[3.5 Input Elements and Tokens]]). Вне контекста типа те же символы — операторы сдвига.

```java
int r = a-- - b;   // токены: a, --, -, b  → (a--) - b
int r2 = a--b;     // ошибка: a, --, b — не выражение (эффект жадной склейки)
```
