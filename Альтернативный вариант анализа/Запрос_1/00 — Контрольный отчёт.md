## Ограничения и незакрытые элементы

- JLS/JVMS извлечены из официальных HTML TOC Oracle SE 25. Официальный subsection сохранён как минимальная доказуемая единица; составные названия помечены для content-level split.

- Boyarsky 830 извлечён из структурных bold headings тела: его краткий Table of Contents недостаточен для атомарного уровня.
- Mughal 830 состоит из Java 21 supplement и базы Java 17. OCR части I потерял некоторые номера; такие строки сохранены с `manual locator repair required`, а не отброшены.

- Engineering scope не имеет утверждённого корпуса источников; все записи имеют `source-required`.
