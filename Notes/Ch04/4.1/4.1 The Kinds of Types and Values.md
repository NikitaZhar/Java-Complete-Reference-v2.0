# 4.1 The Kinds of Types and Values

Java — язык строго и статически типизированный: у каждой переменной, параметра, поля и выражения есть тип, известный уже на компиляции, и компилятор не пропустит операцию, которую этот тип не поддерживает. Практический смысл раздела в том, что почти вся «магия» языка — от того, какой метод вызовется при полиморфизме, до того, почему `==` у строк иногда врёт, — выводится из двух различий: примитив против ссылки и статический тип против исполняемого. Раздел вводит эти различия как понятийный аппарат; конкретные диапазоны примитивов — в [[4.2 Primitive Types and Values]], устройство ссылочных типов — в [[4.3 Reference Types and Values]]. Раздел **не** описывает правила преобразований (это Ch. 5) и не разбирает generics (дом — Ch. 20).
