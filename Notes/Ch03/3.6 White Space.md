Пробельные символы (white space) — это символы, которые разделяют токены, но сами токенами не являются и отбрасываются на третьем шаге лексической трансляции ([[3.2 Lexical Translations]]). Для человека они задают форматирование; для компилятора их единственная роль — граница между токенами там, где иначе те слиплись бы. Форматирование отступами на семантику не влияет (в отличие от, например, Python): блоки задаются фигурными скобками, а не пробелами. Исключение — текстовые блоки, где ведущие пробелы участвуют в значении по особым правилам ([[3.10.5 String Literals]]).

## What Counts as White Space

```
WhiteSpace:
    ASCII SP  — пробел (space)
    ASCII HT  — горизонтальная табуляция (tab)
    ASCII FF  — подача страницы (form feed)
    LineTerminator  — терминатор строки (см. 3.4)
```

Обратите внимание: терминаторы строк ([[3.4 Line Terminators]]) — это тоже пробельные символы. Вертикальная табуляция и прочие «пробелоподобные» Unicode-символы в этот список не входят и пробелами для лексера не являются.

```java
int a = 1;      int b = 2;   // SP и HT между токенами — эквивалентны как разделители
int
c
=
3;                          // переносы строк тоже пробел: это корректное объявление int c = 3;
```

Роль пробела как разделителя видна там, где его отсутствие меняет разбор: `static void` — два ключевых слова, а `staticvoid` — один идентификатор ([[3.5 Input Elements and Tokens]]). Кроме того, наличие пробела влияет на правило longest match: `a - -b` и `a--b` токенизируются по-разному ([[3.2 Lexical Translations]]).
